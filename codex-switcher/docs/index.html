Features

Everything you need, nothing you don't

📊
Live quota bars
5-hour and weekly usage bars update after every background poll. Color-coded green → amber → red so you can see saturation at a glance.
🏆
"Best right now" banner
Instantly surfaces the account with the most 5-hour quota remaining so you can switch without guessing.
🔄
Background polling
Configurable 5–60 minute interval with exponential backoff on rate limits. Your data stays fresh without hammering the API.
🔔
Usage threshold alerts
Set a warning threshold (e.g. 20% remaining) and cards below it get a bell badge so you know before you hit the wall.
↕
Drag to reorder
Drag account cards into the order that matches your workflow. Order persists across relaunches.
🔒
Keychain storage
OAuth tokens live in macOS Keychain, never in plaintext. Tokens are zeroed in memory before deallocation. The UI never sees a raw token.
🕐
Stale data indicator
A clock icon appears on cards whose data is more than 5 minutes old, so you always know whether what you're seeing is current.
📦
Auto-update
Checks GitHub Releases for new versions and prompts you to update — no manual download required.
🔐

All data stays on your Mac

No analytics, no crash reporting servers, no telemetry of any kind. Usage snapshots are stored in a local SQLite database. OAuth tokens go directly into Keychain. See the full privacy policy.

Install

Up and running in 60 seconds

1
Download the DMG
Go to Releases and download Codex.Switcher_*_aarch64.dmg (Apple Silicon) or Codex.Switcher_*_x64.dmg (Intel).
2
Open and drag to Applications
Open the DMG and drag Codex Switcher to /Applications.
3
Clear the Gatekeeper flag
Because the app is unsigned, macOS may say it's "damaged". Run this once in Terminal, then launch normally:
xattr -rd com.apple.quarantine "/Applications/Codex Switcher.app"
4
Add your accounts
Click the menubar icon → Open Codex Switcher → Add, then complete the OAuth flow in your browser.

Paste into Terminal — auto-detects your architecture, downloads the DMG, installs to /Applications, and removes quarantine so it opens first try.

curl -fsSL https://tryingout7.github.io/Codex-Tracker/install.sh | bash

After install: open -a "Codex Switcher"
