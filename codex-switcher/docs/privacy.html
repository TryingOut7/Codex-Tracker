Codex Switcher

Privacy Policy

Effective date: May 2025  ·  Version 1.0

Short version: Codex Switcher stores your ChatGPT OAuth tokens exclusively in your macOS Keychain. No data ever leaves your device. No analytics, no crash reporting servers, no tracking of any kind.

1. What data the app stores

Codex Switcher stores the following data locally on your Mac only:

  • OAuth access tokens — issued by ChatGPT after you log in. Stored in macOS Keychain under the service name com.motosan.codex-switcher. The frontend UI never sees a raw token.
  • Usage snapshots — numeric quota figures fetched from chatgpt.com/backend-api/wham/usage. Stored in a SQLite database at ~/Library/Application Support/com.motosan.codex-switcher/codex_switcher.db.
  • App preferences — poll interval, alert thresholds, and account display labels. Stored in the same SQLite database.
  • Log files — structured diagnostic logs written to ~/Library/Logs/com.motosan.codex-switcher/. Logs contain timestamps, error messages, and account identifiers (UUIDs). Logs are rotated daily and kept for 7 days.

2. Data we do NOT collect

  • No analytics or usage telemetry
  • No crash reports sent to any server
  • No advertising identifiers
  • No personal information beyond what ChatGPT returns in its API response (account email address, plan type)

3. Network requests

The app makes outbound HTTPS requests only to:

  • chatgpt.com — to fetch usage data for your accounts
  • auth.openai.com — during the OAuth login flow (opens in your system browser)
  • github.com — to check for app updates (reads a public JSON file from the GitHub Releases page of this repository)

No other domains are contacted. The app's Content Security Policy enforces this at runtime.

4. Token security

OAuth tokens are written to macOS Keychain using the apple-native keyring backend. Keychain items are scoped to com.motosan.codex-switcher and are not accessible to other apps without explicit user approval. Tokens are zeroed in memory before deallocation using the zeroize crate.

5. Data deletion

To permanently remove all data:

  • Delete the app from /Applications
  • Remove ~/Library/Application Support/com.motosan.codex-switcher/
  • Remove ~/Library/Logs/com.motosan.codex-switcher/
  • Open Keychain Access, search for com.motosan.codex-switcher, and delete any entries

6. Children's privacy

This app is not directed at children under 13. We do not knowingly collect any information from children.

7. Changes to this policy

If this policy changes materially, we will update the effective date above and note the change in the CHANGELOG. Continued use of the app after a policy update constitutes acceptance.
